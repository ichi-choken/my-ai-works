# Raspberry Pi カメラサーバー

Raspberry Pi のカメラを，ブラウザからいつでも確認できるようにした自作サーバーです．外部サービスを介さず，自宅のネットワーク内で完結させることを目的にしています．

## 特徴

- **常時ストリーミングではなく，都度撮影**
  リクエストが来たタイミングで `rpicam-jpeg` を実行して1枚撮影し，画像を返します．常時エンコードを走らせないため，Raspberry Pi の負荷と発熱を抑えられます．

- **単一 HTML の Web UI**
  ブラウザで開くだけで使えます．アプリのインストールや専用クライアントは不要です．

- **LAN と VPN の両方からアクセス可能**
  自宅内では LAN 経由，外出先からは VPN 経由で同じ URL にアクセスできます．ポートを外部公開せずに済むため，インターネットから直接叩かれる経路を作らずに運用しています．

## 構成

| | 内容 |
|---|---|
| 実行環境 | Raspberry Pi |

| UI | 単一 HTML ファイル |
