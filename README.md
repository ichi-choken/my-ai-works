## 作品一覧

### 家計簿アプリ

URL:
https://ichi-choken.github.io/kakeibo/

レシートから商品を細かなカテゴリーへ分類できるようになっています．カテゴリー一覧は自分でカスタマイズ可能です．
また，GeminiのAPIを使用して画像の解析を行い，商品のカテゴライズも自動で行ってくれます．

APIは以下URLから取得:
https://aistudio.google.com/app/api-keys


### スマートリモコン
webサイトから家電製品を赤外線で操作できるようにしました．
操作パネルのボタンをカスタマイズできるようにしてあります．
また，指定時間になったら起動するタイマーも作成しております．
